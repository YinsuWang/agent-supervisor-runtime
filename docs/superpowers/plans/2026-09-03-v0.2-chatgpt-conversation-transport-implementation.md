# V0.2 ChatGPT Conversation Transport Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Connect ordinary ChatGPT Web/Desktop conversations to the durable V0.1 Agent Supervisor Runtime so ChatGPT can plan/review local Codex work with binding, idempotent delivery, read-only context retrieval, browser failover, and crash recovery.

**Architecture:** Preserve the V0.1 `SupervisorAdapter` boundary. Add a ChatGPT supervisor implementation backed by a `ConversationTransport`, durable binding/message/lease stores, a read-only Context Broker, a per-user runtime daemon, Chrome Native Messaging bridge, Chrome extension, semantic ChatGPT page driver, and Playwright background companion. Browser/transport failures remain orthogonal to V0.1 task state.

**Tech Stack:** TypeScript ESM, Node.js >=20.19, Zod, Commander, Vitest 4, Chrome Manifest V3/Native Messaging, Windows Named Pipes, Playwright persistent Chromium, esbuild for extension bundling, `@types/chrome` for extension types.

**Spec:** `docs/superpowers/specs/2026-09-03-v0.2-chatgpt-conversation-transport-design.md`

## Global Constraints

- Node.js floor remains `>=20.19`.
- TypeScript remains the primary implementation language.
- Windows 10/11 and PowerShell 7 are first-class V0.2 targets.
- No public domain, tunnel, second PC, DB server, or Full MCP dependency.
- No OCR, coordinate clicking, physical keyboard injection, or Desktop UI Automation in the normal path.
- No ChatGPT cookies, passwords, access tokens, refresh tokens, or copied session headers in `.orchestrator/` task/runtime state.
- `ContextBroker` is read-only and workspace-scoped; it must not expose arbitrary shell or file writes.
- A binding has at most one ACTIVE sending transport, enforced by a monotonically increasing lease epoch.
- Reconnect/recovery reconciles durable message state before retrying delivery.
- Real ChatGPT is a manual-gated compatibility test, not a required PR-CI dependency.
- The M5 real-page feasibility spike is a hard gate before production live-page browser integration continues.
- Keep known-red TDD commits off shared PR branches where practical; push green candidate checkpoints to reduce CI notification noise.
