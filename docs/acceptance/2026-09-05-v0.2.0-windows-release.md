## 需要处理的问题

1. **优先：CLI 未接入真实 ChatGPT supervisor。** 已安装包 `dist/config/schema.js` 只允许 supervisor.adapter=mock；`dist/adapters/registry.js` 的 buildRuntime 固定创建 MockSupervisorAdapter。源码 run 命令调用该函数。内部 buildConversationRuntime 的模拟集成测试不能替代发布 CLI 的真实流程验收。
2. **doctor 扩展握手误报。** 隔离 daemon 接收 doctor 的 HELLO 后，将其写入 health/extension-session.json，extensionInstanceId=doctor、capabilities=[doctor]。扩展检查接受这一记录，不能证明 Chrome 扩展已连接。主线程独立读取该文件并核对 daemon/doctor 源码确认。
3. **发布包安装与示例说明不完整。** 包不含 examples 和 docs，README 示例依赖 examples，快速开始以源码构建为主。需要提供自包含的发布包安装、扩展目录定位与示例运行步骤，并实际验证。
